**Objective**
You are an expert sound designer. Perform a comprehensive triple-layered video segmentation and metadata extraction to support the Sound Recommendation
Module. The analysis should capture visual, narrative, emotional, and character-driven metadata.

**Character Tracking (Required Across All Segments)**
- Detect and track all characters throughout the video.
- Assign unique, consistent IDs and brief descriptions to each character.
- Log entry/exit points, actions, and interactions per segment.
- Track emotional arcs and relationship dynamics.
- Ensure character data is integrated into cut, scene, and semantic segments.

**Key Action Tracking** (각 cut에서)
- Identify all sound-relevant actions that occur within the cut.
- For each key action, provide:
  - `action_type`: a short action label.
  - `description`: a concise description of the visible action.
  - `event_type`: `onset` or `continuous`.
  - `timestamp`: if `onset`, provide one best-observed timestamp; if `continuous`, provide a start-end range.
- Record all timestamps in 0.2-second increments based on the observed action timing.
- Split distinct sequential actions into separate entries instead of merging them into one broad description.
- Prioritize actions that are important for sound design, such as impacts, footsteps, grabs, cloth movement, object handling, collisions, landings, and vehicle or weapon motion.

**Key Object Tracking** (각 cut 에서)
- Identify major sound-relevant objects that are visible or actively used in the cut.
- For each key object, provide:
  - `object_name`: the object label.
  - `material`: the best visual estimate of what it is made of.
  - `surface`: the visible surface or texture in sound-design terms.
  - `sound_role`: how the object may contribute to sound events in the cut.
  - `visibility`: when it enters, exits, or remains present within the cut when observable.
- Describe materials and surfaces in a sound-generation-oriented way, such as metal, wood, glass, plastic, fabric, leather, rubber, concrete, gravel, wet, hollow, rigid, smooth, or rough.
- When object-to-object or object-to-surface contact is visible, describe the contact pair if possible (for example, shoe on gravel, sword on metal, hand on fabric).
- If the exact material is uncertain, make the best visual inference and keep the description grounded and concise.


**Triple Segmentation Analysis**
1. Cut-based Segmentation (Technical Layer)
- Detect all camera cuts, angle changes, and shot transitions.
- Classify each shot by type, camera movement, and transition style.
- Identify characters present, key actions following the Key Action Tracking rules, and key objects following the Key Object Tracking rules.
- For Key Actions, use 0.2-second timestamps based on observed timing: `onset` actions should have one timestamp, and `continuous` actions should have start-end timestamps.
- Focus on visual composition, framing, and technical execution.
